# `verify`

`verify` is an exact alias for [`validate`](validate.md). It accepts the same flags, runs the same checks, produces the same output, and uses the same exit codes.

```bash
./sysmon-modular verify --base-path .. --all
```

The alias exists for compatibility with workflows that use `verify` as their validation step. See the [`validate` reference](validate.md) for every flag and example.
